**מקרא סטטוס.**

- **בעבודה ב־PR1**: `in progress in PR1 (v6/01-universal-data-contracts)`. עמודת הבדיקה מפרטת את הבדיקות המתוכננות לפי triage A; הן יעודכנו בסוף העבודה לשמות הסופיים.
- **פתוח, מתוכנן PR2/PR3**: `open, planned PR2/PR3`. בדיקות הן הצעה מה־triage, לא קיימות עדיין, אלא אם כתוב "קיים".
- **PR1** = חוזי נתונים אוניברסליים: #13 #15 #16 #18 #22 #23(ייצוא בלבד). **PR2** = מנוע: #10 #14 #21 #23(זיהוי) #26(יעדים מרובים ושיטות) וצד הנתונים של #11 ושל #17. **PR3** = ממשק: #8 #9 #12 #19 #20 #24 #25 #26(ממשק, CSS, כפתור הורדה) וצד הממשק של #11 ושל #17.
