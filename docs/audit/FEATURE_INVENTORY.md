# מלאי יכולות — מנהל הקישורים (v3, לפני השכתוב)

כל יכולת שנראית למשתמש, וכל התנהגות לא־מובנת־מאליה, כפי שהן ממומשות בקוד בפועל.
מספרי השורות מתייחסים ל־`index.html` בתג `baseline-pre-2.0` (`18872b9`). פריסת השורות
זהה ב־`legacy/OtzariaLinker-v3.html`. שורות 1490 ו־1505 הן בלוקי ה־base64 וה־JSZip.

**מקרא:**
- **חובה** — חוזה מול הגנרטור או מול המשתמש. אסור לשנות את ההתנהגות.
- **להחליף** — המימוש חופשי, אבל היכולת חייבת להישאר.
- **לשפר** — ההתנהגות הנוכחית פגומה או חלקית, ומתועדת ב־[`TECHNICAL_DEBT.md`](TECHNICAL_DEBT.md).

סיכום: **142 פריטים** (F-001 עד F-142) ו־**93 בדיקות עצמיות** (§22).
