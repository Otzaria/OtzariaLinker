# ADR 0003 — Preact + Signals לממשק

**מצב:** התקבל · 2026-11-11

## הקשר

הממשק החדש כולל סביבת עבודה עם פאנלים שניתן לשנות את גודלם, רשימות וירטואליות של
עשרות אלפי שורות, אשפים, דיאלוגים, מצב פשוט ומצב מתקדם. בגרסה 3 הוא נבנה ב־DOM
ידני (`Util.h`, `innerHTML`), עם רינדור מלא של פאנל בכל שינוי (`DEVELOPERS.md` §14).

## החלטה

`preact@11` (MIT) ו־`@preact/signals@2` (MIT), שניהם כ־10KB אחרי gzip.

- **Signals** נותנים עדכון ממוקד: שינוי סטטוס של קישור אחד לא מרנדר מחדש את כל הספר.
- **JSX עם בריחה אוטומטית** סוגר את רוב סיכוני ה־XSS מטקסט ספרים. HTML של ספר מוצג רק
  דרך מסנן אחד, מבוקר ונבדק (שלב 17).
- **`src/core` לא מייבא Preact.** הגבול נאכף בבדיקה (ייבוא אסור מ־`core` אל `ui`/`preact`).

## חלופות שנדחו

| חלופה | למה לא |
|---|---|
| DOM ידני כמו בגרסה 3 | זה בדיוק מקור החוב הטכני שתועד |
| React | פי 4 במשקל, בלי יתרון ממשי כאן |
| Solid | מצוין, אבל קהילה ומערכת בדיקות קטנות יותר, וקומפיילר JSX ייעודי |
| Lit / Web Components | Shadow DOM מסבך RTL ועיצוב גלובלי מבוסס טוקנים |
