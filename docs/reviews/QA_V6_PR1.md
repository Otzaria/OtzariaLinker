## 3. ההרצות (שורות תוצאה)

כל ההרצות מהענף בראשו `550ee48` ואילך, ב־Windows, `chrome` בלבד ב־Playwright.

- `npm run typecheck`: נקי.
- `npx vitest run` על `tests/unit/architecture.test.ts`, `tests/contracts`, `tests/unit/{formats,core,ui}`, `tests/unit/linking/{citations,option-specs}`, `tests/integration/{sources,database}` ובדיקות המצב הקשורות: **Test Files 71 passed | 5 skipped (76); Tests 972 passed | 15 skipped (987)**. (15 הדלוגים הם בדיקות `*.local.test.ts` בלי משתני הסביבה.)
- מקומית מול הקבצים האמיתיים (קריאה בלבד): `external-links-real-db.local.test.ts` — 2 passed (סריקה פנימית של 724,985 שורות ב־3.6–3.8 שניות; "ברכות": 162 יעד מחוץ לטווח, 1,210 יעד כותרת, 6,522 כותרת עמומה); `dictionary-collision-real-db.local.test.ts` — 1 passed (שני המסדים עם dictID 32768, בשני הסדרים).
- Playwright (`npm run build` ואז `--project=chrome`) על `routing`, `links-compare`, `home-tasks`, `guided-flow`, `db-links`, `citations`, `engines`, `qa`, `offline-single-file`: **18 passed**. הבנייה: 1,778,601 בתים (תקציב 1.75MiB = 1,835,008).
- בדיקות שנראו נכשלות רק בעומס: ארבע בדיקות "זמן ליניארי" (`export-accounting` property, `export` 100K, `alt-toc` 30K, `mapped-reader` gzip bomb) נכשלו בריצה מקבילה גדולה ועברו בבידוד (4 קבצים, 47 בדיקות). לא נחקר מעבר לכך.
- CI של PR #28 ירוק לפי דיווח המתאם, ובסיסי ההשוואה החזותית של הנתיב והמדריך נכתבו על ידו (`20cb506`); **לא הורצו כאן**.

## 4. מה לא הורץ

- Playwright ב־Edge וב־Firefox; `npm run check` המלא; `npm run test:visual` (נעשה על ידי המתאם ב־CI).
- בדיקת משתמש אנושית; בדיקת הממשק מול מסד אישי (הקורא נבדק בבדיקות אינטגרציה ומקומית, הדגלים עדיין אינם בממשק).
- הרצת OtzariaLinker על v52 דרך הדפדפן; מדידת זיכרון (RSS).
- אימות INLINE_LINKER מול גרסת שחרור של אוצריא (רק `dev`).
- ניתוח הפערים של המשימות (gap-1) היה קריאת קוד בלבד ולא הורצה בדיקה.
