# V7: תיאורי ארבעת ה־PRs

התיאורים מוכנים להדבקה, לפי המבנה של §10 במפרט. כל PR בנוי על הקודם, ולכן ה־diff של כל אחד הוא רק השינויים שלו.
ב־"Issues addressed" אין `Closes`: Issue נסגר ידנית אחרי המיזוג, לפי [`V7_FINAL_REPORT.md`](V7_FINAL_REPORT.md) §ז.

פתיחה (אחרי `gh auth login`), מתיקיית המאגר. הקטע של כל PR נשמר קודם לקובץ, למשל `pr1.md`:

```
gh pr create --base main --head v7/01-data-integrity-security --title "V7 PR1: שלמות נתונים, מסדים, חוזים ואבטחה" --body-file pr1.md
gh pr create --base v7/01-data-integrity-security --head v7/02-linking-correctness --title "V7 PR2: נכונות הקישור, דיוק וקישור אוניברסלי" --body-file pr2.md
gh pr create --base v7/02-linking-correctness --head v7/03-ux-workflows --title "V7 PR3: חוויית משתמש, עריכה וזרימות עבודה" --body-file pr3.md
gh pr create --base v7/03-ux-workflows --head v7/04-validation-release-readiness --title "V7 PR4: אינטגרציה, ביצועים, בדיקות חיות והכנת שחרור" --body-file pr4.md
```

## PR1: שלמות נתונים, מסדים, חוזים ואבטחה

### Summary
מונע אובדן עבודה, שיוך שקט של קישור למהדורה הלא נכונה, ופענוח שגוי של מסדים. מקשיח את הכלי מול קלט עוין: ZIP, ‏regex ומסד פגום.

### Issues addressed
- #41: ‏B10, ‏B15–B21. ‏#42: ‏C1–C4, ‏C22–C24, ‏C29 (חלקי), ‏C30.
- C25 ו־#18: כבר היו ממומשים (#18 מאז PR #28), ונבדקו.
- מפרט V7: §1.1 (חלקי), ‏§1.2, ‏§1.6, ‏§1.7, ‏§1.9–§1.14.

### Root causes
- **שיוך ספר:** הכלי שייך ספר לפי כותרת בלבד, ולקח את הספר הראשון שאינו אישי (B18).
- **שמירה אוטומטית:** כל החלונות שמרו למפתח אחד, `autosave:v1` (B17, ‏B21).
- **מילון zstd:** המילון זוהה לפי `dictID`, אבל המזהה אינו מוכיח את תוכן המילון (B19).
- **`user_link`:** אף קוד לא קרא את הטבלה (B20).
- **ZIP:** ‏fflate פרס כל דחיפה במלואה, לפני שהמגבלות נבדקו (B15).
- **regex:** נבדקה רק צורת הביטוי, לא העבודה שהוא דורש (B16).
- **עץ B:** ההליכה בעץ הוגבלה רק לפי עומק (C2).

ההסבר המלא: [`QA_V7_PR1.md`](QA_V7_PR1.md) §1.

### Implementation
- **זהות ספר:** `resolveTitle(title, origin, source)`. ספר שאין לו התאמה ודאית נשאר לא פתור.
- **שמירה אוטומטית:** מפתח לכל חלון. ‏Web Locks קובע אילו חלונות עדיין פתוחים, ותור שחזור מעודכן תחת נעילה.
- **מילונים:** כל מילון מזוהה לפי SHA-256 ולפי הבעלים שלו.
- **זהות קובץ:** לפי התוכן: גודל, כותרת, ו־SHA של שלוש דגימות.
- **ZIP:** הקלט נדחף בחתיכות של 16KiB.
- **regex:** מודל עלות, עם תקרה של 10,000.
- **מסדים:** `rangeEnd`, ותקציב ביקורים לכל הליכה בעץ.
- **ייצוא:** `exportOutcomes` לכל קישור.
- **CR בודד:** אזהרה, בלי שינוי בפיצול השורות. כך הגנרטור של הספרייה מפצל.

### Regression protection
- **בדיקות נגד באגים:** לכל ממצא בדיקה שנכשלה לפני התיקון. השמות והשורות נמצאים במטריצה.
- **property:** `export-outcomes`, ‏`compare-roundtrip`, ‏`personal-csv-accounting`, ‏`regex-cost`.
- **מסדים עוינים:** `hostile.test.ts`.
- **שני טאבים אמיתיים:** E2E, ‏`autosave-tabs.spec.ts`.

### Tests executed
- **typecheck:** עבר.
- **vitest:** `Tests 2687 passed | 76 skipped (2763)`.
- **E2E (שלושה דפדפנים, אופליין):** `336 passed | 2 skipped`.
- **visual:** `79 passed`.
- **מקומיות מול `seforim.db` ו־v52:** `4 passed`.

הפירוט: [`QA_V7_PR1.md`](QA_V7_PR1.md) §2.

### Before / After
- **ReDoS:** ביטוי שרץ 156 שניות נחסם עכשיו.
- **פצצת ZIP:** קובץ של 1.5MB ניפח 2GB לפני שנעצר. עכשיו הוא נעצר במגבלה.
- **`user_link`:** נקרא כ־0 קישורים. עכשיו הקישורים נקראים, ואם אי אפשר לקרוא אותם, מוצג "לא ידוע".
- **מילון שאול:** טקסט שגוי, בשקט. עכשיו: שגיאה ברורה, או המילון הנכון.

### Breaking changes
- **מפתח השמירה האוטומטית השתנה:** `autosave:v1:w:<id>`. המפתח הישן עובר לתור השחזור, ולא נמחק.
- **שדה רשות חדש בקובץ הפרויקט:** `StoredBook.source`. פרויקט ישן נפתח כמו קודם.

### Remaining limitations
[`QA_V7_PR1.md`](QA_V7_PR1.md) §4. בעיקר: שתי לשוניות שמשוחזרות באותו רגע עלולות להציע את אותה עבודה פעמיים. אין טביעת אצבע
של מהדורה (§1.1).

### Independent review
6 ממצאים. כולם תוקנו, כל אחד עם בדיקה. ביניהם: ReDoS שעקף את המודל, שיוך שקט למהדורה, ואובדן העבודה של חלון רביעי.
[`QA_V7_PR1.md`](QA_V7_PR1.md) §5.
