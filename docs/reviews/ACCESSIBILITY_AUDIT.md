# ביקורת נגישות — מנהל הקישורים 4.0.0-alpha.0

**מה נבדק:** הקובץ הבנוי `dist/OtzariaLinker.html` (ענף `feat/a11y` מ־`rewrite/v2` ב־`dacbec0`), פתוח מ־`file://`
ב־Chrome בלי רשת, 1280×860. כל מסך הופעל כמו שמשתמש היה מפעיל אותו — ובמסלולים העיקריים **במקלדת בלבד**:
הזרימה המודרכת מהכרטיס ועד ההורדה; קישור ידני בסביבת העבודה (בחירת ספרים, בחירת שורות בחצים, יצירה);
אישור ודחייה של הצעות; ייצוא. נבדקו גם מסך הפתיחה, גיליון משימה, תפריטי ההגדרות, הפריסה וההיסטוריה, חלון
העזרה, קישורי המסד, הבדיקה, קישור מרבי ואשף המיפוי.

**איך (בלי axe, בלי תלות חדשה):** הבדיקות כתובות ב־[`tests/e2e/a11y.ts`](../../tests/e2e/a11y.ts):
- **שמות** — מתוך ה־ARIA snapshot של Playwright (חישוב השם הנגיש שלו): כל `button`/`textbox`/`checkbox`/`tab`/
  `radio`/`menuitem`… בלי שם נכשל;
- **מוקד** — `Tab`/`Shift+Tab` עד שמגיעים לפקד; בכל עצירה נבדק שמצויר סימן מוקד (`outline` או `box-shadow`);
- **ניגודיות** — לכל צומת טקסט מוצג: הצבע מול הרקע המצויר בפועל (שכבות רקע שקופות מורכבות, `opacity` של
  האבות מחושבת), יחס WCAG, סף 4.5:1 (3:1 לטקסט גדול). פקדים מושבתים פטורים (WCAG 1.4.3). בנוסף חושבו יחסי
  הטוקנים עצמם (`tokens.css`) בזוגות שה־CSS מצייר יחד, כולל גבולות פקדים (3:1, WCAG 1.4.11);
- **גודל מטרה** — כל פקד מתחת ל־24×24 (WCAG 2.5.8);
- **זום 200%** — חלון 1280×860 בזום 200% הוא 640×430 פיקסלי CSS: גלילה רוחבית של הדף, ופקד שנמצא מחוץ לחלון
  בלי מכל גלילה שמביא אותו.

הבדיקה הקבועה: [`tests/e2e/accessibility.spec.ts`](../../tests/e2e/accessibility.spec.ts) (ראו בסוף).

## מה היה בסדר כבר לפני התיקונים

- **חלונות** הם `<dialog>` עם `showModal()`: הדף שמאחור אינרטי, `Tab` לא יוצא מהחלון (רק לממשק הדפדפן עצמו),
  `Esc` סוגר, והמוקד חוזר לפקד שפתח (נבדק: עזרה, גיליון משימה, ייצוא).
- **זום 200%**: אין גלילה רוחבית ואין פקד שאי אפשר להגיע אליו בשום מסך שנבדק (פריסת המסך הצר נכנסת לפעולה).
- **סימן מוקד** בכל עצירת `Tab` שנבדקה (`:focus-visible` גלובלי; שדות — `box-shadow`).
- **שמות**: לא נמצא פקד בלי שם נגיש בשום מסך שנבדק (כפתורי אייקון כבר נשאו `aria-label`).
- `lang="he" dir="rtl"`, כותרת לדף, אזורים (`banner`/`main`/`region`) עם שמות, הודעות בתוך אזור `aria-live`.

## צבעים: מה השתנה

אף טוקן קיים לא שונה. נוסף טוקן נגזר אחד, `--on-surface-faint` (`color-mix` של `--on-surface-variant` ו־`--outline`
חצי־חצי: `#685d50` בהיר, `#b8aa9a` כהה), לטקסט משני שחייב 4.5:1. השתמשו בו: מספרי השורות (על שורה נבחרת —
`--on-surface-variant`),
placeholder, שורות הצעה שנדחו/קיימות, קישור שיימחק, טקסט לא נספר בשורה. גבול שדות הטקסט והבחירה עבר מ־
`--outline-variant` ל־`--outline`; `kbd` בתוך כפתור יורש את צבע הכפתור.

| מה | לפני (בהיר / כהה) | אחרי (בהיר / כהה) |
|---|---|---|
| מספר שורה על הקורא | 4.28 / 6.0 | 6.11 / 6.84 |
| מספר שורה על שורה נבחרת (מקור / יעד; כהה עם ריחוף) | 3.67, 3.68 / 3.43, 3.39 | 7.64, 7.67 / 5.39, 5.40 |
| `kbd` בכפתור מלא | 1.45 / 1.00 | 6.45 / 7.73 |
| שורת הצעה שנדחתה (טקסט / קטע) | 3.79, 2.78 / 5.02, 4.06 | 6.11 / 8.19 |
| גבול שדה מול רקע השדה | 1.70 / 2.06 | 4.49 / 6.13 |
| placeholder | 4.61 / 4.20 | 6.42 / 8.52 |

**שימו לב:** מספרי השורות, גבולות השדות ושורות ההצעות שנדחו נראים מעט אחרת, ולכן צילומי הבסיס תחת
`tests/visual/` עשויים להשתנות. צילומי `win32` לא עודכנו כאן.

## חלונית הצד: מבנה

הלשוניות עברו לתוך `div[role=tablist]` משלהן, וכפתור ההסתרה נשאר אחריהן בשורה; כשחלונית המקורות מוסתרת,
הלשונית "ספרים" מופיעה עכשיו לפני כפתור ההסתרה ולא אחריו. גוף החלונית הוא `tabpanel`.
