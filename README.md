# מנהל הקישורים של אוצריא

כלי ליצירה, עריכה, בדיקה וייצוא של קובצי הקישורים של ספריית [אוצריא](https://github.com/Otzaria):
הקבצים שמחברים ספר לפירוש שלו, טקסט להערות השוליים שלו, ומקור למקום שהוא מפנה אליו.
בסוף העבודה מקבלים קובצי `<שם הספר>_links.json` בדיוק בפורמט שהספרייה מצפה לו.

> **גרסה 2.0 נמצאת בשלב אלפא.** הגרסה הקודמת (v3) שמורה ב־[`legacy/OtzariaLinker-v3.html`](legacy/OtzariaLinker-v3.html).

## הורדה

**[הורדת OtzariaLinker.html](https://github.com/Otzaria/OtzariaLinker/releases/latest/download/OtzariaLinker.html)**

עד השחרור היציב הראשון, הקובץ נמצא בדף [Releases](https://github.com/Otzaria/OtzariaLinker/releases)
(גרסאות pre-release אינן "latest", ולכן הקישור הישיר עלול לא לעבוד עד אז).

זה קובץ אחד. שומרים אותו במחשב ופותחים בלחיצה כפולה, ב־Chrome, ב־Edge או ב־Firefox. אין התקנה ואין שרת.

- **עובד בלי אינטרנט.** כל מה שהכלי צריך נמצא בתוך הקובץ.
- **שום קובץ לא נשלח לשום מקום.** הכלי לא יוצר שום חיבור רשת.
- **הקבצים שלכם לא משתנים.** מסדי נתונים נפתחים לקריאה בלבד. כל תוצר נשמר כקובץ חדש בתיקיית ההורדות.

## המשימות העיקריות

### קישור פירוש לספר, ידנית

1. פותחים את הכלי וגוררים לחלון את `seforim.db` של אוצריא, או קובץ `.txt` של ספר.
2. בחלונית "מקורות וספרים" מחפשים את הפירוש ולוחצים "מקור". מחפשים את ספר הבסיס ולוחצים "יעד".
3. לוחצים על שורה בספר המקור, ואחר כך על שורה בספר היעד.
4. בלשונית "בונה" הכלי בוחר סוג קשר לפי שמות הספרים (מפירוש אל הבסיס שלו: "מקור"), ומראה איך הקישור
   יופיע באוצריא. אפשר לבחור סוג אחר. הכלי בודק מיד אם אוצריא תקבל את הקישור.
5. לוחצים "יצירת קישור" או <kbd>Ctrl</kbd>+<kbd>Enter</kbd>. טעות? <kbd>Ctrl</kbd>+<kbd>Z</kbd>.
6. בסוף לוחצים "ייצוא", קוראים את הסיכום ומורידים את הקובץ.

### קישור אוטומטי של פירוש

1. פותחים את שני הספרים: את הפירוש כ"מקור" ואת ספר הבסיס כ"יעד".
2. עוברים ללשונית "הצעות", בוחרים שיטה ("לפי כותרות" או "לפי דיבור המתחיל") ולוחצים "חיפוש התאמות".
3. עוברים על ההצעות. "אישור כל הוודאיות" מאשר בלחיצה אחת רק את מה שהכלי בטוח בו.
4. את השאר מאשרים או דוחים אחת־אחת (<kbd>A</kbd> / <kbd>R</kbd> בתצוגת "כרטיס").
5. "בדיקה" ואחר כך "ייצוא".

### קישור הערות שוליים

1. במסך הפתיחה: "קישור הערות שוליים", ובוחרים את הספר ואת ספר ההערות.
2. ודאו שהספר עם סימני ההערות מוצג כ"מקור" וספר ההערות כ"יעד".
3. בלשונית "הצעות" (השיטה "הערות שוליים" כבר נבחרה) לוחצים "חיפוש התאמות".
4. מאשרים, בודקים ומייצאים כמו למעלה.

### תיקייה שלמה של פירושים

1. במסך הפתיחה: "קישור תיקייה שלמה", ובוחרים את התיקייה. פותחים גם את המסד שבו נמצאים ספרי הבסיס.
2. בלשונית "הצעות" (מצב "ספרים רבים (אצווה)") רואים אילו ספרים זוהו: "… על בראשית" מול "בראשית".
3. "חיפוש התאמות". כל ההצעות מכל הספרים מגיעות לרשימה אחת, עם סיכום לפי ספר.
4. מאשרים, בודקים ומייצאים.

### עריכה של קובץ קישורים קיים

1. גוררים לחלון את קובץ `..._links.json` (או ZIP של קבצים כאלה), יחד עם המסד או הספרים שהוא מקשר.
2. בלשונית "קישורים" מסננים, עורכים בבונה, מוחקים או משחזרים.
3. בלשונית "בדיקה" מוצאים קישורים שאוצריא תדחה, ומתקנים.
4. "ייצוא". רשומות שלא נגעתם בהן נכתבות בדיוק כמו שהיו.

### אחרי שספר השתנה

1. פותחים את המהדורה הישנה (שאליה מצביעים הקישורים), את קובץ הקישורים ואת המהדורה החדשה.
2. בלשונית "קישורים": "מעבר למהדורה חדשה של ספר", בוחרים את שתי המהדורות ולוחצים "השוואה".
3. "העברת הבטוחים" מעביר בבת אחת את הקישורים ששורתם לא השתנתה. שורות שנערכו נבדקות אחת־אחת, ושורות
   שנמחקו רק מופיעות ברשימה — הכלי לא מזיז קישור בלי ודאות.

### שמירה והמשך עבודה

- <kbd>Ctrl</kbd>+<kbd>S</kbd> שומר "פרויקט" (קובץ `.otzlinker.json`). פעם הבאה גוררים אותו לחלון, ופותחים שוב את אותם ספרים.
- הכלי גם שומר את העבודה בדפדפן באופן אוטומטי. אם החלון נסגר באמצע, מסך הפתיחה מציע לשחזר אותה.
